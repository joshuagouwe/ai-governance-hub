# Contributing

This monorepo is a curated workspace for AI governance and ISO 42001 resources.

## Scope

Contributions are welcome to:

- improve documentation and cross-references
- add new governance/regulation sources
- clarify usage guidance and recommended workflows
- add metadata, indexes, and maintenance notes

## Guidelines

- Keep repo organization clear and traceable.
- Preserve source provenance in each `ORIGIN.md` file.
- Keep one change per PR when possible.
- Use plain-language, implementation-focused documentation.
- Do not modify upstream content in place without noting provenance and source origin.

## Pull requests

- Keep PRs focused and well-described.
- Link to any relevant upstream issue or source repo if applicable.
- Document whether the change is a monorepo improvement or a sync from an upstream repo.
